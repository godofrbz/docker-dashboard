# Contributing to Docker Dashboard

Thank you for your interest in contributing to Docker Dashboard! This document provides guidelines and instructions for contributing.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/godofrbz/docker-dashboard.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes thoroughly
6. Commit your changes: `git commit -m "Add: your feature description"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Open a Pull Request

## Code Style

- Follow existing code style and patterns
- Use TypeScript for type safety
- Add comments for complex logic
- Keep functions focused and small
- Use meaningful variable and function names

## Testing

- Test all new features manually
- Ensure existing functionality still works
- Run `./test-all.sh` before submitting PR
- Check for TypeScript and linting errors

## Commit Messages

Use clear, descriptive commit messages:
- `Add: Feature description`
- `Fix: Bug description`
- `Update: Change description`
- `Remove: What was removed`

## Pull Request Process

1. Ensure your code follows the project's style guidelines
2. Update documentation if needed
3. Add tests if applicable
4. Ensure all tests pass
5. Request review from maintainers

## Questions?

If you have questions, please open an issue on GitHub.
